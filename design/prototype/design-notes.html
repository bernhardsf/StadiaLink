Design and implementation notes

Window behavior

The preview uses a 32px title bar, a 16px app icon, reserved caption controls, and content reflow instead of scaling a single screenshot. Its caption actions only simulate minimizing, maximizing, and closing this preview.

In the WPF app, prefer standard OS chrome. If custom chrome is retained, use WindowChrome and OS hit-testing so dragging, edge/corner resizing, double-click restore, the system menu, Snap, keyboard access, and DPI changes remain native. Do not substitute browser-style resize handles in production.

Prototype breakpoints at 1100, 800, and 500 CSS pixels are app-specific decisions, not Microsoft-prescribed dimensions. Panels stack first, then navigation collapses. Validate production layout in device-independent units at 100%, 150%, and 200% scaling and with larger text.

Controls and color

Icons come from Microsoft's Fluent System Icons repository under its included MIT license. The dropdowns are native HTML selects styled to illustrate Windows ComboBox controls, not imported WinUI controls. Use the native WPF control template or a compatible Fluent WPF library in implementation.

Six accent presets update selection, controls, and actions immediately and persist in browser storage. The icon's brand colors remain fixed. Production should also consider system accent and high-contrast resources.

Battery

The Fluent Battery 4 asset represents an approximate fill level. The exact 42% reading overlays the icon as a custom product treatment. It is not a stock Fluent battery-with-percentage component. A USB connection alone does not establish charging status or a battery reading.

Controller illustration

I found no Stadia-specific infographic template in Fluent. The diagram should preserve recognizable hardware geometry, while surrounding controls use Fluent conventions. Keep labels readable, use explicit selected states and keyboard-accessible controls, and offer an equivalent input picker. The current browser diagram supports face-button selection and a picker for the remaining inputs.
